# SPRITZ: Complete E-Commerce Catalog & Web Architecture Brief

## System & Inventory Mapping

To support the front-end user experience and backend inventory management, the database must accommodate the following continuous product catalog.

- Products 1-22 (Perfumes Collection): Must be configured with a variant selector on their product pages allowing the user to choose between 50ml (Standard) or 50ml + 15ml (Travel Set)
- Products 23-33 (Duo Set): Fixed bundles. Purchasing these must dynamically deduct stock from the respective core 50ml and 15ml single inventories.
- Products 34-35 (Custom Set): Dynamic pages allowing users to select their own 50ml + 15ml or 3x15ml combinations.
